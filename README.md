# 💻 Portfolio Professionnel - Bineta Sy

Bienvenue sur le dépôt GitHub de mon portfolio en ligne ! Cet espace regroupe la vitrine de mes compétences en ingénierie logicielle ainsi que l'accès au code source de mes différentes réalisations applicatives.


---

## 👩‍💻 À propos de moi
Issue d'un parcours universitaire rigoureux en informatique à l'**UCAD (Dakar)**, j'ai intégré cette année le cycle d'ingénieur spécialisé en **Software Engineering** à l'**ESIEA (Paris)**. 

Passionnée par la conception d'architectures logicielles, mon cursus et mes projets personnels m'ont permis de développer une expertise solide allant du développement d'écosystèmes métiers complets à la mise en place d'architectures distribuées, conteneurisées et intelligentes.

---

## 🛠️ Stack Technique Globale

* **Backend & Serveurs :** Java JEE (Jakarta EE), Tomcat, Hibernate, Spring, Python (Django)
* **Frontend & Mobile :** React.js, Flutter, Dart, HTML5 / CSS3, JavaScript (ES6)
* **DevOps & Outils :** Docker, CI/CD, Git, GitHub, GitLab
* **Bases de Données :** PostgreSQL, SQLite3, MongoDB

---

## 📦 Aperçu des 5 Projets Présentés

1. **🌾 Ecommerce-Agroteranga (Web) :** Plateforme e-commerce écoresponsable en Python/Django pour connecter les producteurs locaux et les consommateurs.
2. **📱 Agroteranga-mobile :** Application mobile compagnon en Flutter/Dart avec gestion du mode hors-ligne pour les acteurs sur le terrain.
3. **🍽️ Gestion-de-Restauration :** Module complet de gestion de restaurant (stocks, commandes, facturation) développé en équipe en Python/Flask.
4. **⚙️ Architecture Microservices :** Système distribué backend hautement disponible, isolé et conteneurisé sous Java JEE, PostgreSQL et Docker.
5. **📄 Translator (Traducteur PDF IA) :** Application d'entreprise en Java JEE déployée sur Tomcat utilisant Hibernate et l'API DeepL pour extraire et traduire des documents PDF complexes.
